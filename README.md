# ArchiveMateAI

A broadcast archive research workspace for newsroom researchers. Find relevant footage, compare source metadata, and refine a research lead with Archie, the built-in AI assistant.

## Features

- Keyword search with optional multilingual semantic retrieval.
- Filters for categories, source playlists, publication dates, and sorting.
- Source playlists grouped by topic, with browsing by publication year.
- Video previews, descriptions, chapters, and links to original YouTube sources.
- Conversational research assistance powered by Gemini.
- Responsive layouts, keyboard navigation, and light and dark themes.

## Stack

SolidJS, Ark UI, and Tailwind CSS on the frontend; Node.js and SQLite on the backend. Local embeddings and USearch power semantic retrieval, while Gemini powers Archie.
